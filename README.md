# nailink-prebuilt

為 ImmortalWrt / OpenWrt 源碼編譯提供 NaiLink 預編譯二進位：

- `daed`
- `btf-probe`
- `luci-proxy`

來源：[slobys/NaiLink](https://github.com/slobys/NaiLink)
